# Bundled report fonts

Inter (sans) and Source Serif 4 (serif), variable weight, from Fontsource. Both are licensed under the SIL Open Font License 1.1 (see the LICENSE files). The files are subset to basic Latin, Latin-1, Romanian letters and common punctuation, symbols and arrows. `render.py` embeds them in each report as data URIs so reports stay offline and self-contained.
